# GitHub release instructions — private staging only

This directory is a local private-staging candidate for the QACE v11.3 strict SP-ablation materials. It does not authorize GitHub access, a commit, a push, a tag, a release, or a licence decision.

After rights-holder approval, the package may be placed under the repository-relative path:

```text
qace-materials/releases/v11-strict-sp-ablation/
```

Do not create a public release until the licence decision, benchmark terms, third-party notices, CITATION.cff metadata, repository URL, release tag/version, and any DOI have been author-confirmed. Before any author-approved upload, rerun the manifest check, review the inventory, and regenerate the manifest after every metadata change.
