# Code Availability

The public repository is https://github.com/miyuheng297-hue/qace-materials-public at tag `public-materials-2026-08-17`. This release provides local aggregate validation and display-check scripts only. It does not provide the KG2RAG retrieval system, BGE or generator weights, benchmark records, prompts, runtime services, raw traces, or an end-to-end rerun implementation.

The strict package therefore supports inspection and validation of the released aggregate tables and their declared relationships, not reproduction of model calls or answer generation.
