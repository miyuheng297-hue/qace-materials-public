# Shared Root Materials Scope

This table describes the path-scoped treatment for the current public package. It is not a blanket repository-wide licence.

| Path class | Treatment |
|---|---|
| Root documentation, attribution, notices, captions, provenance, and audits | CC BY 4.0 for author-produced text where listed |
| `scripts/*.py` | MIT for the distributed author-original validators |
| `figures/Fig1.png`, `figures/Fig1.pdf` | CC BY 4.0 author-produced conceptual display |
| `figures/Fig2.png`, `figures/Fig2.pdf`, `figures/Fig4.png`, `figures/Fig4.pdf` | CC BY 4.0 display treatment; underlying HotpotQA aggregates remain CC BY-SA 4.0 |
| `figures/Fig3.png`, `figures/Fig3.pdf` | CC BY 4.0 display treatment under the MuSiQue scope |
| `LICENSES/*` | Official licence notices, not author-original works |
| `data/*`, `config/*`, and strict aggregate metadata | Controlled by the HotpotQA and MuSiQue scope files |

Editable SVG files and plotting scripts for the current figures are deliberately absent pending item-level public-release authorization. No rights are granted in any third-party dataset, model, software, publication, trademark, or source material named by the documentation.
