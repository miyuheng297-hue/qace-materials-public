# Figure Captions

**Fig. 1** Conceptual overview of QACE as a downstream evidence-selection layer over KG$^2$RAG candidate evidence. (a) High-level system flow from Region A upstream KG$^2$RAG candidate construction, through the Region B QACE evidence-selection layer and selected-evidence-context interface, to the existing Region C answer generator. (b) QACE internal mechanism. Sentence-level BGE rescoring and floor-gated eligibility are core selection steps; route-specific budgeting, minimum-count/minimum-recall refill, and canonical ordering are configuration policies. Supporting-evidence evaluation is based on the selected evidence set, whereas the generator produces the answer. QACE selects only from the upstream candidate set and cannot recover absent evidence. The figure does not depict the frozen QACE selected-evidence trace replay as a fresh online execution.

**Fig. 2** Descriptive configuration-level differences from the Parent-order fixed-7 reference across the 7,405 corrected HotpotQA distractor-dev examples. The corrected JSON-structured protocol was post-hoc and not preregistered. B denotes the Parent-order fixed-7 reference; D denotes the BGE floor-gated fixed-6 configuration; and G denotes the frozen QACE selected-evidence trace replay. Squares denote D minus B and circles denote G minus B. All six absolute metrics are reported in the retained aggregate table. G is a frozen selected-evidence trace replay, not a fresh online execution. The figure presents descriptive configuration-level differences only and provides no inferential interval, significance symbol, or component-level causal interpretation.

**Fig. 3** MuSiQue paragraph-native fixed-pool external validation of 2,417 examples using a fixed pool of 48,315 paragraphs. Run 1 and Run 2 are shown separately and are not averaged or pooled. R5/F5 is an identical-selection alias. Derived Joint is the mean of per-example Answer F1 times paragraph-support F1 and is not Official HotpotQA Joint. This validation is not an end-to-end KG$^2$RAG replication. All bars start at zero; panels use different vertical percentage ranges.

**Fig. 4** Strict supporting-fact selection ablation. (a) Supporting-fact F1 for all 13 allowlisted configurations. (b) Average selected-evidence count for the same configurations in the same order. (c) All 10 predefined SP-F1 comparisons with paired-bootstrap 95% confidence intervals; direction is target minus reference. All panels summarize 7,405 HotpotQA distractor-development samples from one common frozen scored-candidate snapshot. Panel (c) uses 20,000 bootstrap replicates per comparison; colour distinguishes the configuration-level, component-ablation, and sensitivity-analysis families, and filled versus open markers indicate rejection versus non-rejection under the corresponding family-wise Holm decision. The display is SP-only: it generated no Answer EM/F1, Official HotpotQA Joint, answer, or end-to-end metric, and selected-evidence count is not a latency, token, cost, or resource measure. The contrasts are family-adjusted associations under this frozen snapshot, not isolated component-level causal effects.
